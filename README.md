# FitTrack – Daily Fitness & Water Intake Dashboard

FitTrack is a simple and interactive dashboard that allows users to track their daily fitness activities and water intake. The app includes features like:
- Tracking fitness activities (steps, workouts, etc.)
- Recording water intake (in milliliters)
- Displaying daily progress with real-time updates

## Features
- **Fitness Tracker**: Track your daily steps or fitness activities.
- **Water Intake Tracker**: Record your water intake to ensure you're staying hydrated.
- **Responsive Design**: Fully responsive UI that works well on desktop and mobile.
- **Interactive UI**: Buttons to add fitness activities and water intake.

## Technologies Used
- HTML
- CSS
- JavaScript
